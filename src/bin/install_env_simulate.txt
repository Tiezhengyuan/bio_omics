## conda ENV: simulate

install simulation packages
```
conda create -n simulate python=3.9 -y
conda activate simulate
```

install openmm with cuda=11.8, and pdbfixer
    ```
    conda install -y -c conda-forge openmm cudatoolkit=11.8
    conda install -y -c conda-forge pdbfixer
    ```
confirm installation
    ```
    python -m openmm.testInstallation
    ```

install pyrosetta 
    ```
    pip install pyrosetta --find-links https://west.rosettacommons.org/pyrosetta/quarterly/release
    python -c "import pyrosetta; print('PyRosetta is installed')"
    ```

structure biology
    ```
    pip install freesasa
    pip install MDAnalysis netcdf4
    ```

install other packages
    ```
    pip install -r src/bin/requirements.txt
    ```
